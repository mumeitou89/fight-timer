# リングタイマー

Boxing Timer G 風のインターバルタイマー(PWA)。iPhone 6 (iOS 12) の Safari で動く構成。
ビルド不要・外部ライブラリなし・インストール不要のただのHTML/CSS/JS。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` / `app.js` | アプリ本体 |
| `sw.js` | オフライン対応 (Service Worker) |
| `manifest.json`, `icon-*.png` | ホーム画面アイコン等 |
| `audio/` | 録音した声や音を置く場所 (空でOK) |

## 動作確認 (PC)

フォルダで `python3 -m http.server 8000` → `http://localhost:8000` を開く。
(Service Worker は https か localhost でのみ動く)

## 公開 (GitHub → Cloudflare Pages)

1. このフォルダをGitHubのリポジトリにpush
2. Cloudflare ダッシュボード → Workers & Pages → 新規作成 → Pages → GitHubと連携 → リポジトリ選択
3. ビルドコマンドは空、出力ディレクトリは `/` (ルート) のままデプロイ
4. 作成後、カスタムドメインに `timer.自分のドメイン` を追加

以降は `git push` するだけで全端末に反映される。
端末側は、オンラインで1回起動 → もう1回起動すると新しい版に切り替わる (設定画面の下にバージョン表示あり)。

## 端末側の準備 (iPhone 6)

1. SafariでURLを開く → 共有ボタン → 「ホーム画面に追加」
2. 設定 > 画面表示と明るさ > 自動ロック → **しない**
3. 消音スイッチ(横のスイッチ)を **OFF** (Web Audioは消音スイッチで無音になる)
4. 初回は Wi-Fi につないで一度起動 (音声ファイルなどをキャッシュさせる)。以降は機内モードでOK

## 音と声

- 初期状態: ゴング/太鼓/拍子木/ピッは **合成音**、ラウンドコールとかけ声は **端末の日本語TTS** (仮置き)
- 録音ファイルを `audio/` に置くと **自動でそちらが優先**される (無いものだけ合成音/TTSにフォールバック)

| ファイル名 | 用途 |
|---|---|
| `gong.mp3` `taiko.mp3` | 合図の音 (1回分) |
| `clap.mp3` | 残り10秒の拍子木 |
| `r1.mp3` ... `r12.mp3` | 「ラウンド1」...「ラウンド12」 |
| `final.mp3` | 「ファイナルラウンド」 |
| `fight.mp3` `box.mp3` | 「ファイト」「ボックス」 |
| `hajime.mp3` `yame.mp3` | 「始め」「やめ」 |

mp3形式で。ファイルを足したら `sw.js` の `CACHE` の番号を上げておくと確実。

## 挙動を変えたいとき

`app.js` の先頭の `CONFIG` と `PRESETS` を編集。

- 開始時/終了時の打つ回数: `startStrikes` / `endStrikes`
- 連打の間隔: `gap`
- 「ラウンド○」を言い始めるタイミング: `callLead`
- プリセット追加: `PRESETS` に1行足す

## 既知の注意点

- 画面ロック・アプリ切替中は正確に鳴らない (画面を点けたまま使う前提)
- 一時停止からのリセットは「一時停止 → リセット」の2タップ (誤タップ防止)
- 設定変更はスタート前(待機中/終了後)のみ
